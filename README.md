# Auditoria de Software — laboratório de reembolsos

Caso didático para uma aula de 40 minutos com 8 squads. Este é o repositório dos participantes: não contém o gabarito nem a implementação corrigida. Código com falhas intencionais; não usar em produção.

## Comece aqui
1. Leia atividade.md e criterios.md.
2. Consulte evidencias/E1_codigo_numerado.txt e evidencias/E2_execucao.json.
3. Registre achados com critério e evidência; um representante por squad acessa o Kahoot.

## Executar opcionalmente
Python 3.9 ou superior, sem bibliotecas externas. Na raiz desta pasta, execute:
```sh
python executar_cenarios.py
```
Isso imprime as evidências e não modifica arquivos. O JSON fornecido foi gerado pelo mesmo script. Os participantes podem inspecionar todo o material sem instalar nada.

## Limites
Simulação em memória, sem rede, banco ou dinheiro real. Os valores usam centavos inteiros. Não se avaliam concorrência, autenticação real, dados malformados nem retenção em produção.

## Publicação
Repositório da atividade: https://github.com/corazon261/auditoria-software-reembolsos

O acesso foi configurado inicialmente como privado. O proprietário pode convidar participantes ou ajustar a visibilidade antes da aula. O pacote material_apresentadores deve permanecer separado e reservado até o fim da atividade.
