# Acessar e atualizar o caso no GitHub

Acesse https://github.com/corazon261/auditoria-software-reembolsos com uma conta autorizada. O repositório foi configurado inicialmente como privado.

Para obter uma cópia com histórico, execute git clone https://github.com/corazon261/auditoria-software-reembolsos.git e entre na pasta criada.

Para atualizar uma cópia clonada: confira git status, adicione apenas os arquivos desejados com git add, crie um commit e execute git push origin main. Preserve os desvios intencionais durante a atividade. Não envie o pacote completo dos apresentadores, pois contém respostas.
